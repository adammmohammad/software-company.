Brightline Studio is a simple, responsive one-page website for a small software development company. It introduces the company and its services and gives visitors a clear way to get in touch.

The page has four parts:

Header: the company logo and a navigation menu (Home, Services, Contact).
Hero section: a main heading, a short description of what the company does, and a “Get a free quote” call-to-action button.
Services section: three service cards (Web design, Development, Support and hosting).
Footer: contact information (email, phone, address), opening hours, and a copyright notice.

It is built with plain HTML and CSS, with no frameworks, and the layout adapts to phones, tablets and desktops. It was created as a team exercise to practice Git and GitHub collaboration, with feature branches, pull requests and code reviews.
